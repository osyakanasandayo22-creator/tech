# テック・スマイル｜こどもプログラミング教室 ホームページ

こども向けプログラミング教室「テック・スマイル」のランディングページ（1ページ完結型）です。
HTML / CSS / JavaScript のみで作られており、ビルドや外部ライブラリのインストールは不要です。

## 特長

- 明るく親しみやすい、こども向けのカラフルなデザイン
- スマートフォン〜PCまで対応したレスポンシブ対応
- スクロールに合わせたふんわり表示アニメーション
- ハンバーガーメニュー（モバイル）、トップへ戻るボタン
- アコーディオン式のよくある質問（FAQ）
- 無料体験申し込みフォーム（デモ用。送信先サーバーは未接続）

## ページ構成（セクション）

| セクション | 内容 |
| --- | --- |
| Hero | キャッチコピーと無料体験への導線 |
| 概要（About） | 教室の紹介・大切にしていること |
| 特長（Features） | 選ばれる3つの理由 |
| コース・料金（Courses） | 3コースの料金プラン |
| 入会の流れ（Flow） | 申し込みから入会までの4ステップ |
| 体験談（Voice） | 受講生・保護者の声 |
| よくある質問（FAQ） | アコーディオン形式のQ&A |
| アクセス（Access） | 教室情報・アクセス |
| お問い合わせ（Contact） | 無料体験申し込みフォーム |

## 使い方

`index.html` をブラウザで開くだけで表示できます。

ローカルサーバーで確認する場合（任意）:

```bash
# Python が入っている場合
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## カスタマイズのヒント

- 色味は `css/style.css` 冒頭の `:root` 変数（`--pink` など）でまとめて変更できます。
- 料金・コース内容は `index.html` の「コース・料金」セクションを編集してください。
- 住所・電話番号などは「アクセス」セクションのダミー値を実際の情報に置き換えてください。
- フォームは現在デモ動作です。実際に送信するには、フォーム送信処理（`js/main.js`）をメール送信サービスやバックエンドAPIに接続してください。
